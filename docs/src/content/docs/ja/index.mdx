<Legend

>
  Lanternaはシステムの切り替え画面と違い、ウィンドウをリストで並べます。サムネイルを取らないので表示は一瞬で、メモリもほとんど使いません。
</Legend>

<LegendEntries>
  <LegendEntry
    abbr="Lst"
    icon="list"
    index="A1"

  </LegendEntry>
  <LegendEntry
    abbr="Mru"
    icon="history"
    index="A2"
    title="ウィンドウ単位の切り替え"
  >

  </LegendEntry>
  <LegendEntry abbr="2 Pm" icon="key-round" index="A3" title="2つの権限だけ">

  </LegendEntry>
