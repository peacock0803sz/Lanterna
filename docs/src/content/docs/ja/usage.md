## 基本操作

- `Cmd+Tab`で切り替え画面を表示します。`Cmd`を押したまま`Tab`で移動し、`Cmd`を離すと切り替わります。
- `Shift+Cmd+Tab`で逆方向に移動します。
- 文字を入力すると一覧を絞り込めます。
