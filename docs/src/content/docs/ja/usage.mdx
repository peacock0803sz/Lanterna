### ローマ字入力

絞り込み入力はローマ字でも一致します。たとえば`gijiroku`は`ぎじろく`と`議事録`に一致します。かな読みは同梱の変換表でそのまま動きます。漢字読みには辞書が必要です。

### 漢字辞書の用意

漢字読みを使うには、設定ファイルの隣に`migemo-dict`を置いてLanternaを再起動します。

```bash
curl -L -o SKK-JISYO.L https://raw.githubusercontent.com/skk-dev/dict/master/SKK-JISYO.L
curl -L -o skk2migemo.sh https://raw.githubusercontent.com/peacock0803sz/Lanterna/main/scripts/skk2migemo.sh
bash skk2migemo.sh SKK-JISYO.L ~/Library/Application\ Support/Lanterna/migemo-dict
```

SKK辞書はEUC-JPで配布されているため、スクリプトがUTF-8に変換します。送り仮名つきのエントリは対象外で、`/`で区切られた候補はタブ区切りにほぐし、`;`以降の注釈を落として素の漢字だけを残します。リポジトリを持っている場合は`scripts/skk2migemo.sh`をそのまま使えます。

:::note
辞書がない場合や形式が壊れている場合は、かな読みのみにフォールバックします。  
漢字一致を使わないときは`~/Library/Application Support/Lanterna/config.json`に`"romajiScope": "kana"`を指定します。  
キーがない場合の既定は`"kanji"`です。
:::

## ウィンドウ操作

切り替え画面を開いている間にCmdを押しながら次のキーを押すと、選んでいる行のウィンドウやアプリを操作できます。操作しても切り替え画面は閉じず、一覧がその場で更新されます。

|                          |                            |
| ------------------------ | -------------------------- |
| <kbd>⌘</kbd><kbd>W</kbd> | ウィンドウを閉じます。     |
| <kbd>⌘</kbd><kbd>Q</kbd> | アプリを終了します。       |
| <kbd>⌘</kbd><kbd>H</kbd> | アプリを隠します。         |
| <kbd>⌘</kbd><kbd>M</kbd> | ウィンドウを最小化します。 |

既定では、隠したアプリと最小化したウィンドウはほかのウィンドウの下に移り、HIDDEN APPSやMINIMIZEDといった見出しの下にまとめて並びます。操作に失敗したときは表示が元に戻り、短い通知が出ます。Lanterna自身の行は操作できません。開いているウィンドウが無いアプリの行では、閉じると最小化は対象が無いことを知らせ、終了と隠すはそのアプリに効きます。

## 一覧の絞り込みとグループ分け

スイッチャーの表示中に<kbd>⌘</kbd><kbd>/</kbd>を押すと、開いたときに前面にあったアプリのウィンドウだけが並びます。一覧の上の帯にそのアプリの名前が出て、入力した検索語はそのまま残ります。もう一度押すとすべてのアプリに戻ります。次に開いたときは、FilterタブのShow windows ofの設定から始まります。Active appにすると、毎回前面のアプリだけから始められます。

起動したままで開いているウィンドウが無いアプリは、「No open windows」と書かれた行として並べられます。その行を選ぶとアプリが前面に出ます。FilterタブのApps without windowsで、混ぜて並べるか、隠すか、APPS WITHOUT WINDOWSの見出しの下にまとめるかを選べます。既定は隠す設定で、そのときも検索語にアプリ名が合えば見つかります。

Groupsタブで一覧をグループ分けできます。

- By Spaceでは、Spaceごとのウィンドウを見出しの下にまとめます。見出しにはデスクトップの名前と、ディスプレイが複数あるときはそのディスプレイの名前が出ます。表示中のSpaceが先に並び、ほかのSpaceのウィンドウは下の区画ではなく自分のグループに入ります。
- Manuallyでは、最大9つのグループを作り、アプリをバンドルIDで割り当てます。起動中のアプリから選ぶか、IDを入力して足します。見出しには、グループの番号、グループに付けた名前、そのグループのアプリ名のいずれかを出せます。割り当てていないアプリは最初のグループに入ります。

グループ分けしているときは、MINIMIZEDなど下にまとめる区画ごとに、一覧の末尾に置くか各グループの中に置くかを選べます。ただしBy Spaceでは、ウィンドウが無いアプリはどのSpaceにも属さないため常に最後のグループの後に並びます。ほかのSpaceのウィンドウも自分のグループに入るため、その置き場所の設定は使われません。グループが1つしかない一覧には見出しが出ません。

## パネルの表示先と幅

AppearanceタブのShow Panel onで、パネルを出すディスプレイを選びます。Primary display（メニューバーのあるディスプレイ）、Display with cursor（カーソルのあるディスプレイ）、Display with focused window（前面アプリのフォーカスのある窓のディスプレイ）、All displays（すべてのディスプレイ）から選びます。既定はPrimary displayです。All displaysではすべてのディスプレイに同じ一覧が出て、キー入力を受け付けるのはカーソルのあるディスプレイの1枚だけです。切り替えは次に開くパネルから効きます。

同じタブのPanel Widthで、パネルの幅をNarrowからWideまで5段階で変えられます。真ん中の段階が標準の幅です。幅の変更も次に開くパネルから効き、ディスプレイに収まらない幅は収まる大きさに収められます。

同じタブのShow delayで、パネルを出すまでの待ち時間を0から1000ミリ秒まで50刻みで変えられます。0（Off表示）では今までどおりすぐ出ます。待ち時間を入れると、待ち切る前に離せばパネルを出さずに切り替わり、押し続ければいつものパネルが出ます。待ち時間の変更も次に開くパネルから効きます。

## キーバインドの変更

下の一覧のキーはすべて、設定ファイルの `keybindings` か設定のキーボードタブで変えられます。キーは物理位置で扱われるため、入力ソースによらず同じように動きます。

| 操作                       | 既定のキー                               |
| -------------------------- | ---------------------------------------- |
| 表示                       | <kbd>⌘</kbd><kbd>Tab</kbd>               |
| 逆方向に表示               | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Tab</kbd>   |
| 絞り込み用に表示           | <kbd>⌘</kbd><kbd>Space</kbd>             |
| 次へ                       | <kbd>↓</kbd>                             |
| 前へ                       | <kbd>↑</kbd>                             |
| 確定                       | <kbd>↩</kbd>、テンキーの `Enter`         |
| キャンセル                 | <kbd>esc</kbd>、<kbd>⌘</kbd><kbd>.</kbd> |
| 前面アプリだけに切り替える | <kbd>⌘</kbd><kbd>/</kbd>                 |
| 1文字削除                  | <kbd>⌫</kbd>                             |
| クエリ消去                 | <kbd>esc</kbd>                           |
| ウィンドウを閉じる         | <kbd>⌘</kbd><kbd>W</kbd>                 |
| アプリを終了する           | <kbd>⌘</kbd><kbd>Q</kbd>                 |
| アプリを隠す               | <kbd>⌘</kbd><kbd>H</kbd>                 |
| ウィンドウを最小化する     | <kbd>⌘</kbd><kbd>M</kbd>                 |

表示、逆方向に表示、絞り込み用に表示はシステム全体に届き、ウィンドウ操作と前面アプリだけに切り替える操作は入力中に誤爆するため、これらのキーはすべて`Cmd`、`Ctrl`、`Opt`のいずれかが必要です。ほかのアクションが使っているキーは割り当てられませんが、クエリ消去とキャンセルはキーを共有できます。キーが空のアクションは既定に戻りますが、既定も使われている場合はアクションが未割り当てのままになり、診断ログに記録されます。起動用の変更はそのまま反映されます。

## トラブルシューティング

### クラッシュ後にCmd+Tabが戻らない

Lanternaは起動中にCmd+TabとShift+Cmd+Tabをシステムから預かり、終了時に返却します。`kill -9`やクラッシュで終了すると返却できないため、両方のショートカットが無効のまま残ります。

他にできることがある前に、Lanternaが起動していないことを確認してください。復旧処理は現在の状態を読まずにショートカットを有効化するため、別のLanternaが起動したまま実行すると、そのプロセスからショートカットを奪ってしまいます。同時に複数起動することはサポートしていません。

```bash
pgrep -x Lanterna # 何も出なければOK。出る場合は先に `pkill Lanterna` を実行する
```

次にLanternaを起動して正常に終了し直し、終了時の復旧処理でショートカットを戻します。

```bash
/Applications/Lanterna.app/Contents/MacOS/Lanterna &
sleep 1
pkill Lanterna
```

それでも戻らない場合は一度ログアウトして入り直してください。システムのショートカット割り当てはログインセッション単位です。

### ウィンドウが表示されない

アクセシビリティと入力監視の2つの権限が許可されていることを確認し(ガイド参照)、Lanternaを再起動してください。

これで解決しない場合は、[バグ報告テンプレート](https://github.com/peacock0803sz/Lanterna/issues/new?template=bug_report.yml)を使って報告してください。
