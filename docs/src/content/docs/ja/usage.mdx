## 基本操作

<SwitchSequence
  steps={[
    { label: "Hold", keys: ["⌘"], text: "Cmdを押したまま" },
    {
      label: "Step",
      keys: ["Tab"],
      repeat: true,
      text: "Tabで次のウィンドウへ",
    },
    { label: "Release", keys: ["⌘"], text: "Cmdを離すと切り替わる" },
  ]}
/>

|                                        |                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| <kbd>⌘</kbd><kbd>Tab</kbd>             | 切り替え画面を表示します。Cmdを押したままTabで移動し、Cmdを離すと切り替わります。 |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Tab</kbd> | 逆方向に移動します。                                                              |
| <kbd>A–Z</kbd>                         | 文字を入力すると一覧を絞り込めます。                                              |
